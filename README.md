# Download Speed Checker

Консольный скрипт на Node.js для примерной оценки скорости скачивания данных с указанного URL.

## Требования

- Node.js 20 или новее.
- Сторонние зависимости не нужны.

## Запуск

```bash
node index.js "https://example.com/path/to/large-file.jpg"
```

Вместо URL из примера укажите прямую ссылку на достаточно большой доступный по HTTP(S) файл (например, изображение). Скрипт загрузит **его 10 раз**, поэтому общий трафик будет примерно в 10 раз больше размера файла.

## Что делает скрипт

1. Принимает URL из первого аргумента командной строки.
2. Выполняет **10 GET-запросов строго последовательно**: следующий начинается только после полного чтения тела предыдущего ответа.
3. Для каждого запроса измеряет время от начала обращения до полного получения тела с помощью `performance.now()`.
4. Считает число реально полученных байтов, суммарный объём, среднее время запроса и среднюю скорость скачивания.
5. При неуспешном HTTP-статусе, сетевой ошибке или таймауте прекращает замер с сообщением об ошибке.

## Единицы измерения

- **ms** — миллисекунды, среднее время одного полного запроса.
- **bytes** — количество полученных байтов.
- **MB** — мегабайты (1 MB = 1 000 000 байтов).
- **Mbps** — мегабиты в секунду (1 Mbps = 1 000 000 бит/с).

Формула: `Mbps = totalBytes * 8 / (totalTimeMs / 1000) / 1_000_000`.

Это **эффективная скорость загрузки конкретного URL**, включающая задержку соединения и время ответа сервера, а не гарантированная максимальная пропускная способность интернет-канала. Заголовок `Accept-Encoding: identity` запрашивает передачу без HTTP-сжатия; сервер может его проигнорировать.

## Тестирование

```bash
npm test
```

Тест запускает локальный HTTP-сервер и проверяет, что выполнено ровно 10 запросов, они не пересекаются по времени, а в итоговом объёме учтены все байты двухчастных ответов. Интернет для теста не нужен.
